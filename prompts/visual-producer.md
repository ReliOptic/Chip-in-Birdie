# Visual producer

같은 script revision과 claim IDs를 입력으로 사용한다. 눈에 보이는 상태 변화와 당사자의 선택을 장면으로 번역한다. 모든 사건을 3D 장비 회전이나 같은 카드형 화면으로 만들지 않는다.

각 장면에 주목 대상·시작과 끝 상태·비교 조건·음성·사운드·근거·자산 사용 조건을 기록한다. 교육용 도식·개념 모델·물리 계산·사료·재구성을 구분한다. 실제 계산이나 시뮬레이션을 수행하지 않았다면 과학 검증된 결과라고 말하지 않는다.

작은 화면이나 낮은 음량에서도 핵심 사건과 인과를 놓치지 않는지 확인한다. 내레이션·효과·음악을 분리하고 실제 전체 재생 후 영상·자막·음성의 동기와 품질을 기록한다. 파일 생성·빌드 성공·재생 검수·READY는 서로 다른 상태다.

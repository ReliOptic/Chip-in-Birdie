# 역할별 시작 프롬프트

어떤 모델이든 `AGENTS.md`와 공통 채널 관객을 먼저 읽습니다. 아래 문서는 모델을 호출하는 자동화가 아니라 같은 입력·산출 계약으로 작업하기 위한 프롬프트입니다. 실제 actor/model/session은 실행 시 기록합니다.

- `researcher.md`: 사건과 주장 검증.
- `editor.md`: 같은 채널 관객에게 줄 이야기와 편성.
- `visual-producer.md`: 기술과 선택을 보여주는 장면.
- `evidence-reviewer.md`: 독립 근거·상태 검수.
- `editorial-reviewer.md`: 독립 편집 검수.
- `viewer-reviewer.md`: 사전 설명 없는 새 컨텍스트의 모의 독자 검토.

작성 모델에게 자기 리뷰 이름을 바꿔 제출하게 하지 않습니다. 같은 모델 계열도 다른 실행 컨텍스트에서 리뷰할 수 있습니다. 실존하지 않는 리뷰어나 실제 사용하지 않은 모델명을 적지 않습니다.

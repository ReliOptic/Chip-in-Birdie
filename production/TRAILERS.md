# 30초 예고편 (code as video)

## 목적

편마다 30초 예고편을 코드로 만든다. 예고편은 세 가지로 쓴다.

1. **선별:** 어느 편이 눈에 보이는 이야기가 되는지 대본을 쓰기 전에 본다.
2. **G0의 실물:** 예고편은 그 편의 "첫 30초"다. 통과한 예고편은 본편 도입과 히어로 샷이 된다.
3. **Shorts:** 9:16 판을 그대로 올려 주제 수요를 본다.

## 단계

| 단계 | 범위 | 끝나는 조건 |
|---|---|---|
| 0 키트 | `trailers/_kit/` 공용 하네스·검증기·갤러리 | 빈 예제가 검증을 통과 |
| 1 파일럿 | 시즌 1의 6편 (P005 P004 P002 P078 P055 P006), 룩 3종 × 2편 | 감독이 채널 룩 하나를 고름 |
| 2 본 배치 | 나머지 94편, 10편씩 | 배치마다 검증 통과 + 갤러리 갱신 |
| 3 선별 | 100편 채점 | 시즌 2 이후 편성 순서 |

파일럿 전에 100편을 돌리지 않는다. 첫 배치의 결함은 대개 전 편에 공통이라, 6편에서 잡으면 94편을 다시 만들지 않는다.

## 모델

- **기본: GPT-6.1 Sol.** 94편 본 배치와 파일럿 제작.
- **GPT-6 Astra:** 0단계 키트, 파일럿의 룩 설계, Sol이 검증을 두 번 넘지 못한 편.
- 제작 모델의 "검증했다"는 보고는 증거로 치지 않는다. `verify.mjs`의 출력과 스냅샷만 본다.

## 산출물 계약

```
trailers/
  _kit/            harness.js  verify.mjs  gallery.html  README.md
  P005/            index.html  trailer.json  shots/*.png
  index.html       전체 갤러리 (자동 생성)
  ledger.json      편별 룩·hero 기법·팔레트·전환·소리 모티프·검증 수치
```

- **형식:** 30.0초, 30 fps, 16:9 기본 + 9:16 전환(배치를 `W·H`에서 다시 계산). 단일 HTML, 외부 요청 없음.
- **결정성:** 프레임은 `t`의 순수 함수. `Math.random`·`Date`·타이머·CSS transition 금지. 난수는 시드 고정, 무거운 계산은 `setup()`에서 한 번.
- **진입점:** `window.__seek(t)`, `window.__meta={title,duration,fps,aspects,setAspect,audio}`, `window.__ready=true`, `#headless`에서 UI 숨김.
- **소리:** `OfflineAudioContext`로 합성. 큐마다 따로 구워 고정 순서로 합산. 음성 없음. 30초에 큐 6–10개, 모티프 하나.
- **글:** 영어. 화면 글자는 질문 한 문장과 단어 타이밍 자막. 숫자·연도·고유 사실은 `episodes/<P>/claims.csv`에서 `NEEDS_PRIMARY` 이상인 것만 쓴다. 없으면 질문과 장면만으로 만든다.
- **영상 파일 금지:** MP4·GIF를 만들지 않는다. 검증 스냅샷 PNG는 편당 12장 이하.
- **기법:** [cokacmotion](https://github.com/kstost/cokacmotion) 데모에서 만드는 방법만 가져온다. 데모의 소재·구도·문구·색은 가져오지 않는다. 편당 hero 1 + 보조 2 이하.

## 30초 구조

| 구간 | 할 일 |
|---|---|
| 0–3초 | 첫 프레임부터 사건의 물체가 화면에 있다. 훅 |
| 3–12초 | 무엇이 이상한가. 주인공 물체는 모든 샷에 남는다 |
| 12–24초 | 메커니즘이 한 번 눈에 보인다. 상태가 바뀐다 |
| 24–30초 | 질문 한 문장. 답하지 않고 끝낸다 |

샷 5–8개. 절정 직전 컷이 가장 짧다. 전환 효과는 2종 이하, 나머지는 컷.

## 검증 (편마다, 자동)

`node trailers/_kit/verify.mjs trailers/P005` 가 아래를 `trailer.json`에 기록한다.

- 콘솔 오류 0
- 같은 `t`를 두 번 그려 바이트 동일
- 프레임 시간 p95 (CPU 15 ms, 3D 100 ms 이하)
- 16:9·9:16 양쪽에서 8개 시각 스냅샷, 빈 화면·잘림 없음
- 소리 버퍼를 두 번 구워 해시 동일
- 화면 글자가 `claims.csv` 규칙을 지켰는지 목록으로 출력

하나라도 실패하면 그 편은 `FAILED`로 남기고 갤러리에 표시한다. 통과로 고쳐 쓰지 않는다.

## 선별 채점 (감독, 편당 1분)

| 항목 | 질문 | 0–2 |
|---|---|---|
| 훅 | 3초 안에 계속 볼 이유가 생겼나 | |
| 보임 | 메커니즘이 설명 없이 눈으로 이해됐나 | |
| 질문 | 끝의 질문에 답을 듣고 싶나 | |
| 본편 | 이 장면이 8분을 끌고 갈 물체·비유를 줬나 | |

합계 6 이상이 편성 후보. 룩의 완성도는 채점하지 않는다. 룩은 파일럿에서 한 번 정하고 고정한다.

예고편은 주제가 눈에 보이는지와 훅을 시험한다. 8분 유지율은 시험하지 못한다.

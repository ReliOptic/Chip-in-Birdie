# Chip in Birdie

**반도체를 통해 기술·산업·돈·사회의 맥락을 이해하는 영어권 교양 다큐멘터리 채널.**

하루 종일 반도체와 관계없는 일을 한 사람도 잠들기 전에 보고 “아, 그래서 이런 선택을 했구나”라고 이해할 수 있어야 합니다. 쉬운 진입과 깊은 해석을 함께 추구합니다.

이 저장소는 여러 모델과 사람이 같은 채널 기준으로 연구하고, 편집하고, 서로 리뷰하며 결과를 누적하는 운영 공간입니다. 모델 API나 YouTube 업로드를 자동 실행하는 서비스는 아닙니다.

| [채널 헌장](channel/CHARTER.md) | 반도체·산업·경영·경제·사회의 연결과 시청 경험 |

## 이번 기준의 핵심 변경

**타깃 오디언스는 채널 단위로 한 곳에서 관리합니다.** 각 영상은 같은 관객에게 줄 사건과 이해를 설계합니다. 기존 S1–S5는 과거 주제 관심 분류로만 보존하며 영상별 타깃으로 사용하지 않습니다.

YouTube 추천은 시청자·영상·상황에 맞춰 개인화됩니다. 채널 운영에서는 동일한 사람이 서로 다른 영상에서도 얻을 공통된 보상을 만들고, 실제 유입과 재방문 데이터를 통해 이를 수정합니다. 알고리즘의 고정 고객군이나 성공 가중치를 추정해 사실처럼 사용하지 않습니다. 공식 근거는 [출처 목록](channel/SOURCES.md)에 있습니다.

## 실제로 할 수 있는 일

```bash
python3 tools/channel.py status
python3 tools/channel.py brief H039
python3 tools/channel.py validate
python3 -m unittest discover -s tests -v
```

Python 표준 라이브러리만 사용합니다. `brief`는 채널 공통 관객을 상속한 작업 맥락을 만들고, `status`는 현재 작업과 데이터 상태를 보여줍니다. task/review 명령은 리비전·파일 해시·독립 검토를 연결합니다. 자세한 명령은 `python3 tools/channel.py --help`와 [공동 작업 절차](ops/WORKFLOW.md)를 보세요.

## 편집 자산

- [원본 H001–H100](editorial/catalog.json): 원제·사건·기술·선택·공개 연구 단서·후속 제안 계보. 제목과 공개 순서는 승인되지 않은 작업 기록입니다.
- [재선정 P001–P100](editorial/proposals.json): 기존 원본을 재구성한 70개, 병합 6개, 신규 24개를 구분합니다.
- [작업 대기열](work/tasks): H095 자산 회수·채널 적합성 재검토, H039 서사, H080 원리와 선택의 연결. 첫 공개 순서를 뜻하지 않습니다.
- [모델 역할 프롬프트](prompts): 조사·편집·시각화·독립 검수·비전공 시청자 관점 검토.
- [제작 양식](templates): 에피소드 브리프, 주장, 장면, 미디어 묶음, 리뷰 근거.

## 사실과 실행 상태

현재 실제 YouTube Analytics는 연결하지 않았습니다. 시청자 규모·CTR·재방문율을 임의로 채우지 않습니다. 원본의 과거 상태와 현재 영상 검증 상태를 구분합니다. 작업 `DONE`, 영상 `READY`, 플랫폼 `PUBLISHED`도 별도입니다.

2026-11-11의 기존 통합 패키지 v1은 출처 조사 이력으로 보존되지만, 영상별 S1–S5 타깃 배정은 이번 사용자 지시로 폐기했습니다. 현재 기준은 이 저장소의 [관객 정의](channel/AUDIENCE.md)입니다.

다음 모델은 [AGENTS.md](AGENTS.md)를 먼저 읽고 현재 작업을 인수합니다. 원문·전체 영상·개인 접근 권한이 필요한 작업은 확보 여부를 기록하고, 그 부분을 검증했다고 추정하지 않습니다.

# 261117 | Chip in Birdie 실행 백로그 — 제가 처리할 순서

## 확인된 현재 상태

- **정본:** `main`의 4시즌 × 8편 = 32편, 순서는 S1E01 → S2E01 → S3E01 → S4E01 뒤 E02 묶음. 편성은 PR #3으로 병합됐으며 공개일은 정해지지 않았다.
- **현재 제작:** [PR #4](https://github.com/ReliOptic/Chip-in-Birdie/pull/4)는 `draft` / `open`이고 S1E01을 `IN_PRODUCTION`으로 올리는 변경을 담는다. 메인 브랜치의 `NOT_STARTED`와 PR #4의 제작 초안 상태를 혼합하지 않는다.
- **이미 만든 것:** S1E01 영어 원고 1,029단어, 약 469.882초의 합성 VO, 약 6초의 웨이퍼 핸드오프 장면, 음성 타이밍·WebGL 재생 코드·제작 근거. 실제 미디어 파일은 Git main 밖의 별도 검토 에셋에 있다. 수치와 파일 존재는 PR 작성자의 보고 및 manifest이며 이 작업에서 재생·SHA를 독립 재검사하지 않았다.
- **미완성:** S1E01의 전체 영상, 사실에 고정된 역사적 결정 장면, 대본 잠금, 소리/영상/권리/시청 경험의 독립 릴리스 QA. PR #4는 `CHANGES_REQUESTED`이며 완료된 본편 수는 **0**으로 보고한다. 현재 YouTube 공개 상태는 연결되지 않았으므로 확인된 공개 편수라고 바꾸어 쓰지 않는다.
- **운영 검사:** 2026-11-17의 `main` 로컬 클론에서 `channel.py validate`, `check_catalog.py`, 단위 테스트 33개가 통과했다. 구조 검사이며 영상의 진실성·재미·사용권 확인이 아니다.

## 이번 외부 레퍼런스 반영

[판보는형 벤치마크](../editorial/benchmarks/261117_panboneun_narrative.md)는 사건→돈·기술·시간 제약→당사자 선택→검증 가능한 다음 신호라는 서사의 통찰만 재사용한다. 기존 채널의 폭넓은 교양 관객과 영어 정본, 역사적 사실의 정확성, 3D로 보이는 상태 변화가 더 높은 기준이다. 참고 채널이 쓰는 의혹성 사건의 단정·복제 가능한 편집/영상 자산·영상 길이·조회수는 제작 규칙으로 승격하지 않는다.

## 하지 않을 일과 상태 표현

- PR #4의 활성 제작 파일을 이 벤치마크 작업에서 덮어쓰거나 새 작품으로 리셋하지 않는다. 기존 claim과 검수 지적을 존중한다.
- 사용자 승인 없는 결제, 유료 추론, 자동 업로드·예약·알림·게시를 수행하지 않는다.
- `TASK DONE`, `script locked`, `READY`, `PUBLISHED`를 서로 바꿔 쓰지 않는다. 외부 검토자가 부족하면 작업을 리뷰 대기로 남긴다.
- H095/TASK-001과 H080/TASK-003은 별도 준비 대기열이다. 공식 32편의 초기 제작 순서와 혼합하지 않는다.

**이 문서는 실행 판단의 작업 메모이며 새 공개 순서·타이틀·길이·완성 승인 결정이 아니다.** 우선 P0→P4로 S1E01의 첫 실제 본편을 완결하는 것이 산출물 중심의 다음 작업이다.

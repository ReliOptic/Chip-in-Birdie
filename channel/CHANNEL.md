# 채널

## 약속

반도체를 통해 뉴스·기업·돈·사회의 사건이 왜 그렇게 됐는지 이해하게 한다.

## 관객

채널 전체가 한 관객을 공유한다. 영상마다 타깃을 따로 정하지 않는다.

**시청 상황:** 반도체와 무관한 일을 긴 하루 동안 하고, 잠들기 전에 영상을 연다. 준비·메모·용어 검색 없이 따라올 수 있어야 한다. 피곤하다는 조건이지 얕게 만들라는 뜻은 아니다.

**반복 보상:** 익숙한 뉴스나 뜻밖의 사건을 따라가다 기술 조건을 이해하고, 사람·기업·국가가 왜 그렇게 선택했는지 알게 된다. 다음 날 비슷한 소식에서 관계가 보인다.

**유입 가설 네 가지** (값은 [audience.json](audience.json), 미측정):

| 들어오는 관심 | 다음 편을 볼 이유 |
|---|---|
| 시사·경제 뉴스의 맥락 | 뉴스 뒤의 산업 구조를 읽는 경험 |
| 기업·경영·돈의 선택 | 기술을 알아야 설명되는 선택과 대가 |
| 과학·기술의 뜻밖의 장면 | 원리가 제품·조직·생활까지 이어지는 이야기 |
| 역사·사회·제도 | 오늘의 결과를 당연하게 보지 않는 관점 |

시즌 1의 여섯 편이 네 가설을 나눠 시험한다. ([편성](../editorial/PROGRAMMING.md))

## 고정 값

| 항목 | 값 |
|---|---|
| 정본 언어 | 영어. 한국어 퍼포먼스가 의미·강조·쉼의 기준 |
| 개국 언어 | 영어 오디오 + 한국어 오디오 트랙 + 영·한 자막 |
| 길이 | 8–9분 기본(설계값 510초). 대본이 요구하면 6–12분. 늘리려고 채우지 않는다 |
| 주기 | 주 1편, 고정 요일 |
| 개국 조건 | READY 3편 + 대본 잠금 3편 |
| 감독 | 방향·대표 샘플·예외만 본다. 장면마다 승인하지 않는다 |
| READY | 같은 리비전의 근거·권리·음성·영상·자막·메타데이터 + 독립 QA |

값의 기계 판독본은 [charter.json](charter.json), 결정 이유는 [DECISIONS.md](../DECISIONS.md)에 있다.

## 경계

- 기술 조건이 선택과 결과를 바꾸지 못하는 소재는 다루지 않는다.
- 산업의 구조나 방향을 바꾸지 않은 사고·일화는 한 편으로 만들지 않는다.
- 경제·사회 해석은 당사자의 선택에 붙인다. 이론 이름을 덧붙이지 않는다.
- 사실·인용·해석·도해·재구성을 화면에서 구분한다.
- 직무 교육, 종목 추천, 일일 헤드라인은 만들지 않는다.
- 제작자의 현업·고객사와 맞닿은 주제(P030, P034, P037–P040, P047, P050, P097)는 모든 주장이 공개 출처로 채워지고 이해상충 점검을 마친 뒤에만 편성한다.
